# Submission checklist
- [ ] Install PostgreSQL and run `backend/db/schema.sql`.
- [ ] Configure `backend/.env` with DATABASE_URL and a strong JWT_SECRET.
- [ ] Start backend; verify `/api/health`.
- [ ] Start frontend; test each demo login.
- [ ] Test purchases, transfers, assignments and role restrictions.
- [ ] Deploy backend and frontend; set environment variables.
- [ ] Verify public URLs before submitting.
- [ ] Export project documentation to PDF.
- [ ] Record a 3–5 minute walkthrough.
- [ ] Upload the ZIP with source code and schema.
Do not submit fake hosted URLs. Ask the form owner whether a repository or local demo is acceptable if deployment is not completed.
